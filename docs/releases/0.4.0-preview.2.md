# MTM 0.4.0-preview.2

MTM 0.4.0-preview.2 is the MTM-011 protocol-default cutover preview.

## New-run workflow default

- Workflow protocol 3 is the default when `MTM_WORKFLOW_PROTOCOL_VERSION` is unset.
- Workflow protocol 2 remains supported through the explicit rollback override
  `MTM_WORKFLOW_PROTOCOL_VERSION=2`.
- Existing protocol-2 and protocol-3 runs are not rewritten by the default change.
- The workflow/finalizer authority boundary, state schema 2, public tool count 24, and
  `proof_verified.tex` finalization gate are unchanged.
