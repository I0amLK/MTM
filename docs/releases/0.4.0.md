# MTM 0.4.0

MTM 0.4.0 is the first stable release candidate promoted from the accepted
0.4.0-preview.3 behavior after MTM-013 hardening and release qualification.

The stable contract keeps:

- Rust as the sole MTM production authority;
- workflow protocol 3 as the default for new runs;
- `MTM_WORKFLOW_PROTOCOL_VERSION=2` as an explicit workflow rollback;
- state schema version 2;
- 24 public tools and 11 hidden legacy aliases;
- `proof_verified.tex` as the sole mechanically finalized mathematical artifact;
- compact TUI by default with `--verbose` diagnostic fallback;
- preview.3 as a selector-level release rollback during the 0.4.0 qualification window.

MTM-013 adds two hardening fixes before stable promotion:

1. a transport-corrupted `CAPABILITY_INVALID` can obtain a fresh owner/run-checked
   task envelope only before any write; the malformed token grants no authority and
   the original submission is never executed automatically;
2. `complete_flow_locally_validated` now comes from the RuntimeApplication
   composition fact and is reported consistently by the gateway and `server_info`.

Stable support claims remain limited to the target environments explicitly covered
by the recorded release evidence. Other operating systems and deployment layouts
require independent qualification.
