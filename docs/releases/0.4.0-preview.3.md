# MTM 0.4.0-preview.3

MTM 0.4.0-preview.3 is a presentation-only TUI usability preview built on the
accepted protocol-3-default behavior from preview.2.

## TUI information hierarchy

The default `mtm tui` monitor is now compact:

- startup identity, workflow protocol and Native mode share one short line;
- the local MCP endpoint remains visible;
- a generated OAuth operator key is still shown exactly when the user needs it;
- each tool is shown once when it starts, for example `tool: rethlas_step`;
- successful tool completion no longer adds a second routine line;
- tool failures remain explicit as `tool failed: <name>`;
- trace identifiers, argument-key lists and allow reasons are hidden by default;
- routine Quick Tunnel starting/closed events are silent while the public tunnel URL
  and tunnel failures remain visible.

Use `mtm tui --verbose ...` to restore the prior detailed redacted lifecycle format.
Verbose mode may show trace identifiers and argument-key names, but never argument
values, OAuth secrets, bearer tokens or workflow capabilities.

## Unchanged behavior

- workflow protocol 3 remains the no-override default for new runs;
- `MTM_WORKFLOW_PROTOCOL_VERSION=2` remains the explicit rollback;
- state schema remains 2;
- public tools remain 24 and hidden aliases remain 11;
- verifier/finalizer, OAuth, Native/workflow authority and `proof_verified.tex`
  semantics are unchanged.
