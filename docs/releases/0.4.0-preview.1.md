# MTM 0.4.0-preview.1

MTM 0.4.0-preview.1 is the first installable preview of the MTM-009 mathematical
research-state work.

## Release posture

- Rust remains the sole MTM runtime authority.
- SQLite state schema remains version 2.
- Workflow protocol 2 remains the default for new runs.
- Workflow protocol 3 is supported as an explicit opt-in evaluation mode.
- Protocol 1 and protocol 2 stored runs remain compatible.
- The public tool catalog remains 24 public tools and 11 hidden aliases.
- The workflow state set remains unchanged.
- The only final mathematical artifact remains `proof_verified.tex`.

Enable protocol 3 for a newly launched MTM process with:

```bash
MTM_WORKFLOW_PROTOCOL_VERSION=3 mtm tui --quick-tunnel --native-mode dangerous
```

## Protocol 3

Protocol 3 adds a deterministic mathematical dependency/obstruction projection,
strict structured research records, and a bounded advisory research context for
Generator and Repair roles. Advice is non-authoritative: it cannot transition the
workflow, issue capabilities, set verifier verdicts, or finalize artifacts.

The terminal TUI now shows the active tool lifecycle explicitly, for example
`[tool:start] rethlas_step ...` followed by `[tool:done] rethlas_step ...`. Only tool
names and argument-key names are rendered; argument values such as capabilities or
secrets are never printed by this display path.

Verifier, Branch, and Assembler roles do not receive the global mathematical research
view. Verifier findings are normalized into the Repair view only.

## Evidence status

Engineering, compatibility, rollback, and resource non-regression gates for the
preview have passed. A paired eight-case structural simulation also supports the
direction of the research-control design, but that simulation is explicitly not A4
real-web evidence and cannot authorize a protocol-3 default cutover.

The MTM-009 milestone therefore remains in progress. A later release may make protocol
3 the default only after the separately frozen real-web mathematical acceptance gate
passes.

## Rollback

The accepted MTM 0.3.0 Rust release remains the rollback target. Protocol-3 copied
state has been demonstrated to resume under that prior binary while preserving the
same state schema and finalizer path.
