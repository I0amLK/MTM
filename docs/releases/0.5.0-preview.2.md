## Scope

Preview.2 preserves the MTM-014 Rust Native permission authority, Bubblewrap Linux
isolation actuator, workflow protocol 3 production default, protocol 2 explicit
rollback, schema-2 state, verifier/finalizer authority and 24-tool public MCP surface.

MTM-015 adds:

- non-overwriting persistent OAuth/capability-secret initialization with owner-only
  permissions and winner reuse;
- opt-in redacted capability issue/submission diagnostics;
- distinct authorization, logical-submission and tool-failure operator outcomes;
- a bounded same-run caller recovery helper that permits at most one retry after the
  existing zero-write recoverable `CAPABILITY_INVALID` contract returns a fresh task;
- a permanent 500-round current-source normal capability gate;
- RFC 9728 protected-resource discovery for the configured `/mcp` resource, while
  preserving legacy origin metadata and the authorization-server issuer at the origin.

No rejected capability authorizes writes, no server-side automatic submission replay
was added, and no production workflow/project/proof state migration was performed.
